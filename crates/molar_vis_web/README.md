# Embed the viewer in a Rust web application

The `molar_vis_web` library lets a browser application own a molecular viewer
on an existing canvas. The crate also supplies the standalone viewer built with
Trunk. For Cargo setup, a Rust example, and the edit event reference, see the
[Rust embedding guide](../../docs/BUILD.md#embed-the-viewer-in-a-rust-web-application).
